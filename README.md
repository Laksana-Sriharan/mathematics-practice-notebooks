# Mathematics Notebooks

This repository contains Jupyter notebooks created while studying mathematics concepts as part of my Mathematics for AI module.

## Topics Covered

- **Matrices:** Matrix operations and related concepts
- **Vectors:** Vector operations and properties
- **Determinants:** Determinant calculations and properties
- **Probability:** Basic probability concepts and problems
- **Probability Distributions:** Different distributions and their applications

## Technologies Used

- Python
- Jupyter Notebook
- NumPy
- Matplotlib

## Purpose

The purpose of this repository is to practice mathematical concepts using Python and maintain a collection of notebooks for learning and future reference.
